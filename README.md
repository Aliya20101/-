# Expense Tracker — учёт личных расходов

**Автор:** *Фахртдинова Алия
**Дата:** 04.05.2026
**Вариант:**Expense Tracker (Трекер расходов)
## Описание программы

Это простое графическое приложение для учёта личных финансов. Оно позволяет добавлять расходы с указанием суммы и категории (например: *еда*, *транспорт*), фильтровать записи по дате или категории и подсчитывать общую сумму трат за выбранный период. Все данные сохраняются в файл `expenses.json` для последующего использования.

Приложение написано на языке Python с использованием библиотеки Tkinter.
